# พลังงานหมุนเวียน · Renewable Energy

ชุดบทเรียนออนไลน์สองภาษา (ไทย / อังกฤษ) สำหรับนักศึกษาชั้นปีที่ 2 สาขาวิศวกรรมเกษตรอัจฉริยะ
เปิดใช้งานได้ทันทีโดยไม่ต้องติดตั้งอะไร — ดับเบิลคลิก `index.html` หรือใช้ Live Server ใน VS Code

## โครงสร้างไฟล์

```
index.html                     สารบัญ / หน้าแรก
chapters/
  01-introduction.html         บทที่ 1 · บทนำสู่พลังงานหมุนเวียน
assets/
  css/base.css                 ตัวแปรสี ตัวอักษร เลย์เอาต์ การสลับภาษา
  css/components.css           การ์ด กล่องเน้น รูป ตาราง สูตร อ้างอิง แบบทดสอบ
  css/anim.css                 แอนิเมชันและภาพจำลองแบบโต้ตอบ
  js/boot.js                   ตั้งภาษา/ธีมก่อนหน้าเว็บวาด (กันหน้าจอกระพริบ)
  js/app.js                    สลับภาษา สลับธีม แถบความคืบหน้า สารบัญด้านข้าง
  js/quiz.js                   ระบบแบบทดสอบก่อนเรียน/หลังเรียน

```

หนึ่งบทเรียน = หนึ่งไฟล์ `.html` สไตล์ทั้งหมดอยู่ในไฟล์ `.css` ส่วนกลาง ไม่มี inline style

## การรองรับสองภาษา

เขียนเนื้อหาทั้งสองภาษาไว้คู่กัน แล้ว CSS จะซ่อนภาษาที่ไม่ได้เลือก

```html
<p class="th">ข้อความภาษาไทย</p>
<p class="en">English text</p>
```

ใช้ได้ทั้งกับ block (`<p>`, `<li>`, `<td>`) และ inline (`<span>`) รวมถึง `<text>` ใน SVG
ภาษาที่เลือกถูกจำไว้ใน `localStorage` และมีผลกับทุกหน้า

## แบบทดสอบ

แต่ละบทมีสองชุด วางไว้ที่ต้นบทและท้ายบท

```html
<section class="quiz" id="pretest" data-quiz="pre" data-pass="0.6">
  <script type="application/json" class="quiz-data">
  { "questions": [
      { "q": { "th": "คำถาม", "en": "Question" },
        "choices": [ { "th": "ตัวเลือก ก", "en": "Choice A" },
                     { "th": "ตัวเลือก ข", "en": "Choice B" } ],
        "answer": 1,
        "why": { "th": "คำอธิบาย", "en": "Explanation" } }
  ] }
  </script>
</section>
```

- `data-quiz` — `pre` หรือ `post`
- `data-pass` — เกณฑ์ผ่านเป็นสัดส่วน (0.6 = 60%)
- `answer` — ดัชนีของตัวเลือกที่ถูก **เริ่มนับจาก 0**
- ข้อความใน JSON เป็นข้อความล้วน ใส่แท็ก HTML ไม่ได้ (ระบบจะ escape ให้อัตโนมัติ)

**ทั้งสองชุดเฉลยทันทีที่ส่งคำตอบ** พร้อมคำอธิบายรายข้อ ต่างกันเฉพาะข้อความสรุปท้ายชุด
(pre-test ชี้ว่าควรโฟกัสหัวข้อใด ส่วน post-test บอกว่าผ่านเกณฑ์ `data-pass` หรือไม่)

ผลคะแนนเก็บใน `localStorage` ของเครื่องนักศึกษาเท่านั้น **ไม่มีการส่งข้อมูลออกไปที่ใด**
หากต้องการเก็บคะแนนจริงเพื่อประเมินผล ต้องเพิ่มระบบหลังบ้านแยกต่างหาก

## เอกสารอ้างอิง

ทุกบทต้องมีส่วน `<section id="references">` ท้ายบท (ก่อน post-test) และเพิ่มลิงก์ในสารบัญด้านข้าง
ใช้โครงสร้าง `.references` แบ่งกลุ่มด้วย `<h3>` เช่น ตำราหลัก / รายงานและสถิติ / บทความวิชาการ /
แหล่งข้อมูลของประเทศไทย เลขอ้างอิงสร้างอัตโนมัติด้วย CSS counter จึงต้องใส่ `start="n"`
ในแท็ก `<ol>` ของกลุ่มถัดไปเพื่อให้เลขต่อเนื่อง

```html
<li><span>Twidell, J. and Weir, T. (2015). <cite>Renewable Energy Resources</cite>,
  3rd ed. Abingdon: Routledge.
  <span class="src">หมายเหตุว่าอ้างส่วนใด</span></span></li>
```

## สมการ (LaTeX)

สมการพิมพ์ด้วย **KaTeX ที่เก็บไว้ในโปรเจกต์เอง** (`assets/vendor/katex/` — 23 ไฟล์ ~550 KB)
จึงแสดงผลได้แม้ไม่มีอินเทอร์เน็ต ไม่ต้องพึ่ง CDN เขียนเป็น LaTeX ตรง ๆ ใน HTML

- แบบแสดงกลางบรรทัด `\[ E = P \times t \]`
- แบบแทรกในข้อความ `\( \mathrm{CF} = 16.1\% \)`

```html
<div class="formula">
  <div class="formula__row">
    <div class="formula__eq">\[ E = P \times t \]</div>
    <span class="formula__num">(1.1)</span>
  </div>
  <div class="formula__where">\(E\) = พลังงาน (kWh) · \(P\) = กำลัง (kW)</div>
</div>
```

> **ห้ามใส่ข้อความภาษาไทยไว้ในสมการ** (เช่น `\text{พลังงาน}`) เพราะฟอนต์ของ KaTeX
> ไม่มีอักษรไทย จะกลายเป็นกล่องสี่เหลี่ยม ให้เขียนคำอธิบายไว้นอกเครื่องหมาย `\( \)`
> และใส่เฉพาะหน่วยภาษาอังกฤษด้วย `\mathrm{}` เช่น `\mathrm{kWh}`

เนื้อหาที่สร้างขึ้นหลังโหลดหน้า (เช่น เฉลยแบบทดสอบ) เรียก `window.RE.renderMath(el)`
เพื่อจัดพิมพ์สมการเพิ่มได้

## แอนิเมชัน

ใช้เมื่อการเคลื่อนไหว *อธิบายบางอย่างได้* เท่านั้น เช่น ทิศทางการไหลของพลังงาน
หรือการสะสมของปริมาณตามเวลา ไม่ใช้เพื่อความสวยงามอย่างเดียว

| สิ่งที่ใช้ | วิธีใช้ |
|---|---|
| ค่อย ๆ ปรากฏเมื่อเลื่อนถึง | ใส่ `data-reveal` บนอิลิเมนต์ |
| ปรากฏไล่ทีละรายการ | ใส่ `data-reveal-stagger` บน `<ul>` / `<ol>` |
| เส้นพลังงานไหลในแผนภาพ | ใส่คลาส `dg-flow` บน `<g>` ของเส้นเชื่อมใน `.figure` |
| ภาพจำลองแบบโต้ตอบ | `<div class="demo" data-demo="ชื่อ">` แล้วเขียนตัวควบคุมใน `anim.js` |

ทุกอย่างปิดตัวเองอัตโนมัติเมื่อผู้ใช้ตั้งค่า `prefers-reduced-motion: reduce`
และสถานะ "ซ่อนก่อนปรากฏ" ผูกกับคลาส `.anim-ready` ที่ JS เป็นคนเติม
ดังนั้นถ้า JavaScript ไม่ทำงาน เนื้อหาจะยังแสดงครบ

## การเพิ่มบทใหม่

1. คัดลอก `chapters/01-introduction.html` เป็นไฟล์ใหม่
2. แก้ `<body data-chapter="01">` ให้เป็นเลขบทใหม่ (ใช้เก็บผลคะแนนแยกรายบท)
3. แก้ `<title>`, หัวบท, สารบัญด้านข้าง, เนื้อหา และแบบทดสอบทั้งสองชุด
4. เขียนส่วน `#references` ของบทนั้นใหม่ให้ตรงกับเนื้อหา
5. แก้ลิงก์ "บทต่อไป" ของบทก่อนหน้า และของบทใหม่
6. ใน `index.html` เปลี่ยนการ์ดของบทนั้นจาก `href="#" aria-disabled="true"`
   เป็นลิงก์จริง แล้วเพิ่ม `data-progress-for="NN"` ในช่อง `.chapter-card__status`
7. ตรวจว่าท้ายหน้ามีบล็อก `.copyright` ครบ

## การเผยแพร่ผ่าน GitHub Pages

เว็บไซต์นี้เป็น static site ล้วน ไม่ต้อง build ไม่ต้องมีเซิร์ฟเวอร์ จึงวางบน GitHub Pages ได้ตรง ๆ

**ครั้งแรก**

```powershell
gh auth login                       # ล็อกอิน GitHub (ทำครั้งเดียวต่อเครื่อง)
gh repo create renewable-energy --public --source=. --remote=origin --push
gh api -X POST repos/:owner/renewable-energy/pages -f "source[branch]=main" -f "source[path]=/"
```

รอประมาณ 1–2 นาที เว็บจะขึ้นที่ `https://<ชื่อผู้ใช้>.github.io/renewable-energy/`

**อัปเดตเนื้อหาครั้งต่อไป**

```powershell
git add -A
git commit -m "เพิ่มบทที่ 2 ชีวมวล"
git push
```

GitHub Pages จะอัปเดตอัตโนมัติภายในไม่กี่นาที นักศึกษาเปิดลิงก์เดิมได้จากทุกอุปกรณ์

ไฟล์ `.nojekyll` มีไว้บอก GitHub Pages ว่าไม่ต้องประมวลผลด้วย Jekyll ห้ามลบ

## หมายเหตุ

- **สมการใช้งานออฟไลน์ได้** เพราะ KaTeX ถูกเก็บไว้ใน `assets/vendor/katex/` แล้ว
- ฟอนต์ IBM Plex ยังโหลดจาก Google Fonts อยู่ หากออฟไลน์จะถอยไปใช้ฟอนต์ระบบโดยอัตโนมัติ
  (เลย์เอาต์และสมการยังถูกต้องครบถ้วน เปลี่ยนแค่หน้าตาตัวอักษร)
- ตัวเลขสถิติในบทเรียนเป็นค่าโดยประมาณเพื่อการสอน ควรอ้างอิงแหล่งปฐมภูมิที่เป็นปัจจุบัน
  (พพ., สนพ., PDP/AEDP ฉบับล่าสุด, IRENA, IEA) ก่อนนำไปใช้อ้างอิงจริง
- KaTeX เป็นซอฟต์แวร์ของบุคคลที่สาม เผยแพร่ภายใต้สัญญาอนุญาต MIT
  (ดู `assets/vendor/katex/`) ลิขสิทธิ์ของ KaTeX เป็นของผู้พัฒนา KaTeX ไม่ใช่ของผู้จัดทำบทเรียนนี้
